# AVENOX ANDROID

An Android-only agentic engineering system planned around official Avenox Beyin and Codex Cloud.

## Status

Avenox Beyin V3.10.0 is installed in this Cloud environment. Its writable runtime is configured outside the repository; runtime databases and machine-specific configuration are excluded from Git. The official health and preferences checks are used to verify the installation. Codex lifecycle-hook execution has not been observed in this environment.

The Android knowledge foundation is a metadata-only source registry with decision and verified-lesson templates under `knowledge/android/`. No Android application, SDK, Gradle installation, or project tool-version baseline is present.
